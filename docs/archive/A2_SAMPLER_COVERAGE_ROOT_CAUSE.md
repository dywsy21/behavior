# A2采样覆盖缺陷：真实证据与修复

2026-09-11；本人单独检查和实施。修复尚未用于新训练，不是成功率改善声明。

## 根因

原采样器只随机化task顺序及各片段内的帧；每个task的片段列表仍按源文件顺序开始。与此同时，每轮长度用所有task的平均片段容量计算。任务等额轮转时，长任务需要的槽位多于平均值，尚未到队尾就结束一轮，下轮又从同样的开头开始。因此单纯多训到下一轮，仍不能保证接触这些尾部片段。

实际A2训练在4192步结束第一轮，后续808步再次从队首采样。完整核对四rank、5000步、8万条实际样本；只采用合法前3000步及正确续训3001–5000，排除旧run checkpoint之后的额外记录和错误Adam续训。

|任务|应有训练演示|实际接触|完全未接触|合法技能片段/实际接触|
|---|---:|---:|---:|---:|
|收音机|190|190|0|760 / 760|
|捡垃圾|190|190|0|2280 / 2280|
|万圣节|190|126|64|5045 / 3354|
|盘子|190|181|9|3532 / 3354|
|肉罐头|190|125|65|5153 / 3354|

这是本轮A2的实际暴露量，不等于祖先A5000从未看过这些演示。收音机、捡垃圾已覆盖全部演示，所以此缺陷不能解释它们的所有接触抓取失败；意图响应弱与接触控制仍需另外解决。

## 已实现的独立候选

`a2_lora_history_candidate_v7_samplercoverage`仅改变采样实现，原v6、已训练权重、运行中的仿真和主仓模型代码均未热改。默认仍为原`source_order_v1`，新模式必须显式设置`leaf_ordering=episode_round_robin_v1`。

- 每个task先遍历各条演示，再轮转各演示内部打乱后的技能片段。
- 每轮长度按照最长task的片段数分配，避免队尾永久饿死。
- 每片段采用所有rank共享的独立随机排列，再切分帧，避免懒初始化随机流受rank访问顺序影响。旧两轮实际同epoch的跨rank样本集合仍存在交集；新5000步的六组rank交集全为0。
- 保持原train/eval切分、合法源池、原始条件、动作、边界mask和模型结构不变。新旧采样顺序不是等价resume，不伪装旧采样状态续接。

14项原/新采样回归通过，包括长任务尾部覆盖、不同rank不交叠、新模式断点重建、确定性及旧默认兼容。

## 真实Dataset验证

从原正式配置实际构造8,898,502帧的train Dataset；其源图经JSON规范化后与训练时保存的源图完全相同。旧模式实际重建8万条采样顺序，逐条等于正式训练记录。

同一真实Dataset的新模式：每task在前250步均接触全部190条演示；5000步时全部950条演示均被接触，task2/4各覆盖4000个技能片段；一完整轮为6442个每rank batch，并覆盖每个合法片段。5000步仍非看完全部帧/片段，不能夸大。

没有构造模型、没有CUDA初始化、没有optimizer或物理更新。这项验证只证明采样调度修复，处理后batch与后续权重/成功率仍须验证。
