# MEM-Lite v10：原地打转问题的改进与训练记录

截至 **2026-09-08 11:20（北京时间）**。改进、正式 5,000 步训练和本轮独立验收均已完成。**短时诊断0/5成功，问题没有根治；不能把实验完成说成方法有效。** 详见[最终结果报告](MEMLITE_V10_RESULTS.md)。

## 为什么改这些

[v9 根因报告](MEMLITE_V9_SPIN_ROOT_CAUSE.md)中的关键证据不是“看起来在转圈”，而是：

- 五任务全部 70,126 条动作在策略端和模拟器端逐项一致，排除了桥接传错动作。
- 实际动作编码器能准确表示停转及正反向旋转，停转 yaw 重建 MAE 仅 0.000420。
- 在同一真实回放观测上，只改变底盘速度历史，模型预测 yaw 可从 +0.27362 变为 +0.00124，反向速度历史又会产生 −0.28771。速度反馈对动作选择有直接因果影响，但不是唯一因素。
- 全部 950 个训练 episode 的状态 yaw 与下一段专家动作高度相关，已经转动时需要立即停转的样本相对稀少；原有高层主要见过成功轨迹，没有真实旋转失败后的恢复监督。

因此修复针对“速度捷径 + 状态转移监督不足 + 缺少真实恢复闭环”，而不是硬改 yaw 正负号或简单限制转速。

## 已实现

| 层面 | 实际改动 | 边界 |
|---|---|---|
| 低层输入 | 训练时以 50% 概率遮蔽底盘三维速度历史；推理固定使用带 `withheld (unknown, not zero speed)` 标记的遮蔽表示 | 只改模型条件；真实状态、GT 动作、监控数据不变。高层保留真实速度 |
| 动作监督 | 对躯干/底盘动作码的 CE 权重设为 2；单独记录该组损失与准确率 | 格式、文本、夹爪等 token 权重仍为 1；没有换回 FM，也没有重训 ActionCodec |
| 采样 | 每张卡 batch8 固定含：1 高层、1 停转、1 启动/换向、1 夹爪变化、1 恢复低层、3 其他低层 | 五任务均衡；四卡源样本归属不重叠；同一张卡内允许合理重复 |
| 真实恢复数据 | 在训练实例中实际执行旋转偏离、刹车、重新对准、接近、稳定，保存真实三相机历史及动作 | 公共测试 instance301 不并入训练；恢复轨迹不等于完整任务成功示范 |
| 高层与记忆 | 真实恢复数据中的反馈、恢复意图、REPLAN/CONTINUE 和记忆更新保持因果顺序 | 不凭未来轨迹编造“已经完成”；恢复后原操作仍待完成 |
| 运行时监控 | 根据真实速度及 RGB 重复识别长时间无接近进展的旋转；暂停一块动作并要求高层重算 | 不给策略输入真实目标坐标/全局位姿，不永久覆盖动作，不把护栏当成成功策略 |
| 动作还原 | 躯干/双臂相对动作使用未裁剪的真实当前状态作为还原锚点 | 底盘始终是速度，不做相对位姿累加；此修复不被冒充为已经证实的旋转主因 |
