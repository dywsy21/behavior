# H29：去掉无效前进检查的距离盲区

负责人：Codex父；2026-09-21，北京时间。代码待独立审查，尚未部署。

H25原始起点回合接近收音机时，VLM反复选底盘前进；这时原执行器仍给出了可行的手臂动作，
不是所有其他动作都被IK拒绝。旧`ApproachProgress`只检查手—观测接触点距离≤10厘米的情况。
实际反复前进发生在约11–15厘米，因而始终不积累失败反馈。

先固定重放d80–127，再扩展到已完成的整个抓取接近段d47–127：

- 81份保存状态的原FK/closing center距离重新计算，旧检查结果与线上记录无不一致。
- 仅去掉10厘米豁免，首次触发在d100：此前三次实际底盘前进50.55毫米，
  依照观测运动、假设目标静止，应缩短50.73毫米；实际接触点距离反而增加1.52毫米。
- d47–99没有提前禁用前进。合法远距离接近、跨10厘米边界、缺测、持物、导航、
  重复同一帧与不足三次测量等测试保留或增加。

这里只证明“预期进展持续没有发生”。接触点可能改变，目标可能移动，视觉测量也可能不稳；
不能据此断言撞到了物体，也不能把保存数据重放当成新策略成功。本人检查d97/d100/d127
原始头部图像，手和收音机确实接近，但没有获取物体真值来替部署决策。

修改仅影响已显式开启的`--approach-progress`：移除距离豁免，不改原有实际运动≥12毫米、
三次独立执行、累计预期收益、方向性限制或测量恢复条件，也不改IK、碰撞和成功阈值。
保留可行的其他手臂/转向/退让动作。既有冻结H25与Astra的1fcc版本均不热改。

作者测试446项/9.628秒、SFT兼容151项/4.417秒通过。实际新实现对全部81份输入的
离线对照通过；不同数值环境最大浮点差2.50e−16，按1e−12核验，分类/事件/窗口长度完全一致。
后来发生的重放事件沿用的是旧策略实际轨迹，不是新veto后的反事实轨迹；不据此推算成功率。
