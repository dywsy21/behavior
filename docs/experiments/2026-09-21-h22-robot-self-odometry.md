# H22：让环境里程计排除机器人自身

负责人：Codex父；Astra独立终审。2026-09-21 11:51 BJT登记≤1800s CPU块。
唯一假设：头相机中机身/手臂随机器人运动，违反里程计的静止环境假设；
在拟合前以当前机器人几何排除这些点，可以减少错误位移和非必要停机。
原起点官方成功仍是goal；本块本身没有新reset、模型或训练许可。

## 实现

- 新`--odometry-self-exclusion`缺省关闭，只允许显式六控制步的joint RGB-D路径。
- 沿用同一SIFT匹配和深度可靠性检查。每个匹配的两个3D端点各转换到该时刻
  机器人底座坐标；任一端落在机器人视觉link盒内，就在求解前排除。
  不按拟合残差挑遮罩、不混试求解器，不改变25内点/.45比例等门槛。
- 只使用当前机器人自己的视觉资产与关节/手指FK；没有场景分割、物体真值、
  世界位姿或任务结果输入。link集合/静态bounds/边距必须与标定资产一致。
- 每次采样重新取实际native link变换，包含闭爪后的真实手指位置；采集前后
  q/夹爪不许变化。帧同时绑定q、夹爪、控制钟、RGB-D内容，缺失或陈旧就拒绝。
- 每个六步片段和完整动作证书带几何帧hash。动作结束的精确图像、状态和几何
  一起复用，不能用下一帧的几何冒充原测量。SEARCH新局部参考也继承过滤选项；
  不扩大原搜索恢复资格、不把未知位移补写为有效。
- 全部被排除或环境纹理不足仍停止。机器人视觉盒是保守近似，可能误排紧贴的
  环境点；不能把通过里程计当无碰撞证明。持物自身运动和其他动态物体仍不是
  静态世界，当前修改不宣称解决全部动态场景。

保存态审计脚本对整轮所有实际片段固定重算旧/新路径，不挑通过的片段；
只有开手且实际开度不变时才允许离线搬运旧robot-only盒。**这种搬运仅用于
诊断，部署实际取每帧手指FK**。原图像/深度hash与FK必须同原链。
