# H40：小幅位置调整的两步提示（默认关闭）

负责人Codex；CPU票见`configs/semantic_robot/h40_translation_preview_cpu_block.json`。当前只实现/作者测试，未部署，不能声称提高了成功率。

## 为什么增加这个提示

H38实际第75次决策的同一机器人状态：直接前伸3cm过不了原IK检查；延长64到256次迭代仍残留约5.38mm位置误差。先上移1cm再前伸3cm则能通过原机器人检查。两个上移坐标系候选使预测距离从.5133m降到.4820/.4785m。其余安全约束没有降低。这不是永久死锁：原H38后来自己继续到了约.239m，但最终NO_MOTION_PROGRESS/官方失败，仍待完整失败审。

原提示已经展示“旋转一下，是否能再前伸”，却没有展示“先小幅平移，是否能再前伸”。即时距离收益不包含这层关系。H40只补这一信息，不写收音机专用动作顺序。

## 运行方式与边界

- 显式`--approach-translation-preview`，默认关闭；依赖已有无负载接近资格及机器人几何检查。工程门、manifest与result须同开关，旧门不能冒充新门。
- 仅可见、无危险、单手PICK的APPROACH，所有持物/未验证闭爪标志明确为false、实际双手张开且命令锁存也张开、目标距离大于10cm。
- 只有当本轮coarse手臂平移均未通过时触发。选1个当前被机器人路径检查拒绝、但预测距离改善的coarse跟随动作；可见环境障碍拒绝不作为此预测的触发依据。
- 从**已经过当帧深度＋机器人预检**的fine平移中，取至多3个不同方向、正即时收益的候选。各增加1次原Servo预检，最多3次；不新增动作、不调整原预检数量/时长/速度/碰撞阈值。
- 提示只标注现有候选的两步收益、跟随动作和总预测tick。模型只能选当帧第一步；第二步不是授权、不是队列，必须重新观察、重新完整检查。
- 全部是静止表面假设下的机器人几何预测，不保证未来环境安全、可见性、抓姿或抓取成功。也不使用仿真物体真值。

高层MEM-Lite和子SFT原生动作接口均未改。当前两个实验的冻结源码未动。
