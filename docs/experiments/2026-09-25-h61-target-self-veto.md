## 假设与范围

本票只改同一公共定位入口和必要测试：当前所选像素及其深度聚合点落在已导出的robot base visual surface 6mm范围内即拒绝。缺失本体标定明确unknown并拒绝接触定位；不把非重合当完整非机器人/身份/抓取/接触/持有/成功证明。单个视角报本体时不通过丢掉该视角绕过；多视角平均点也检查。原始选中像素无有效深度不使用邻域填成可用接触点。

范围不包括完整robot mesh、按压手指FK、检测器新prompt/阈值、模型训练或对已见12查询再次推理；所有旧运行源码/结果保留不热改。此为后继新commit的接口变化，无base geometry的旧标定将不能作新接触定位，必须明确记录而非静默fallback。
