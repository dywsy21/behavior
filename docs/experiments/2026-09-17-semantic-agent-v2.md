## 实测中发现并修正的两个根本执行问题

1. **Jacobian参考点混用。** PhysX线速度在link质心，link pose在prim原点。初版导出直接混用，两末端恰好接近正确，右腕相机却在prefix64偏10.14mm。按固定机器人质心偏移换算后，同位置最大误差2.485微米；后续radio33组校验最大3.043微米。15个旧真实状态（含接近关节限位、旧空抬/转腕）离线对照native link pose，最大2.00微米。此修正证明相机/躯干导出问题，**不证明旧10cm手部追踪误差全由它造成**。
2. **“最终可达”不等于“短窗口内能做到”。** task3收拢姿态，预检多轮IK接受1cm UP，实际18帧只抬1.54mm。无物理、完美跟踪回放仍只抬1.74mm，排除必须诉诸碰撞/模型错误的解释。改为同一已验证轨迹执行后，CPU真实本体fixture在32帧抬8.52mm，误差1.48mm（原容差2.5mm不变）；真实仿真复验抬8.5208mm/误差1.4806mm，与CPU预测相符。

中间旧版radio控制门曾24/24完成、349新控制，最大位置残差0.0288mm/角度0.00979°；这是修改轨迹前的结果，保留作工程证据，**不可推广到新版本/全部工作空间**。旧task3门失败立即安全停机，共37控制，没有放行VLM。
