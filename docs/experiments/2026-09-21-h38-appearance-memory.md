## 设计

- `--appearance-memory`依赖`--near-contact-review`，默认旧行为不变。
- 只在无已记录负载/待验抓取的单手PICK之SEARCH、RECOVER、APPROACH、ALIGN使用。抓取验证、运输、双手、其它任务阶段沿原完整观测路径；不会用一张身份参考来判断持握。
- 缓存只能由**当帧真实选中的表面**创建，须经过原同帧receipt和当前RGB/深度/实际机器人状态检查，且距手中心≤25cm。保存一张原crop、来源hash和目标身份，不保存用于驱动动作的旧UV/3D点。
- 下一次普通观察改为H37已经验证的“3张当前RAW＋1张明确标为非当前的外观参考”，不额外增加观察调用。只返回当前定位，enclosed/co_moving/supported/effect均未知。
- 使用参考的当前定位必须再做一次**当前**表面选择，共享原来16次额度；即使初始深度平整有效，也不能绕过。弃权、无候选或额度耗尽时由H33拦住该点的接近动作。
- 精确目标内容/索引变化、负载/验证阶段、看不见、表面弃权会清除；最多存活8次普通观察，只有新的真实语义选点才能刷新。不会因重复使用而自动续期。
- 观察、refine和controller使用同帧图像/关节/夹爪绑定；旧参考只帮助辨认外观。日志保存实际送入模型的参考PNG及来源hash，不能只有文字“用了记忆”。

这是harness的短期视觉身份提示，不是MEM-Lite语言记忆，不引入仿真对象ID/分割/真值位姿，也不改变动作、夹爪、成功判据。
