# H-07：可观测几何、有限搜索与可执行动作接口

负责人Codex，2026-09-18；独立分支`feat/semantic-agent-grounded-20260918`。这是[H-06](SEMANTIC_AGENT_V2.md)失败后的通用接口改进，不是每任务手写轨迹、MEM-Lite新训练或完整成功率证明。实际状态以[plan](plan.md)为准。

## 为什么改

H-06揭示了三个不同缺口：模型识别radio但不知道实际夹持位置；机械臂受限时仍选不可达方向；找不到桌子时反复小幅转向且无覆盖记忆。更大的VLM没有自动补足机器人几何、控制可行性和搜索状态。

现在的分工是：VLM识别目标/操作部位、规划子目标和选择动作；确定性接口计算合法传感器中的位置关系、过滤不可达动作、记录实际搜索覆盖。两者都不能自报官方成功。

## 数据流和边界

| 环节 | 输入与职责 | 不做什么 |
| --- | --- | --- |
| 机载观察 | 原生head720×720、两腕480×480，RGB＋`depth_linear`米制图像平面深度，本体q/开度/局部速度 | 不读目标pose、分割真值、接触/抓取状态、世界pose或全场景点云 |
| 可见事实 | VLM给当前可见操作部位像素，可选两个真正对应的其他视角 | 看不清给unknown，不用任务名称当持物证据 |
| 目标几何 | 5×5深度中位数，洞/范围/深度边界拒绝，跨相机差异>7cm拒绝；反投影到当前机器人坐标 | 仅是表面点估计，不是完整物体姿态、抓取位姿或深度真值标注 |
| 夹持参照 | 两侧机器人资产定义指面点均值；用本体FK映射到相机和底座 | 不把EEF原点、偏出画面的坐标或静止的开夹指尖当实际夹持点 |
| 候选预检 | H-08 B4每轮至多24个非HOLD动作，按不同物理方向保留备选；原SafeServo完整有限关节计划验证，记录收益和拒绝 | 不执行试探动作、不改变主执行器夹爪锁存、不绕过关节/速度/路径门 |
| 搜索 | H-08启用`--visual-odometry`后，用有质量门的机载RGB-D测量记录24个方位区间；每次8°命令后重新观察 | 发出命令或旧速度积分不等于真实转角/新增覆盖；没有隐藏房间地图 |
| 反馈/恢复 | 非空夹爪＋真实微抬＋视觉随动＋深度随动交叉确认；3次普通恢复、最多2次策略重规划 | 不删除未完成目标、不编造已持物；预算耗尽安全停止 |

[官方规则](https://behavior.stanford.edu/challenge/evaluation.html)允许RGB、深度和本体状态。现有评测框架已经启用RGB-D；新接口**只读提取已有传感器数据，不重新设置相机或重载环境**，未热改或升级共享OG3.9.1环境。首次适配错误地重复赋值相同分辨率，也会触发原生render-product重建并失效PhysX视图，已修并保留失败证据。正式3.9.2包装与独立成员审查仍待办。

## 执行细节

- `run_v2.py --harness grounded`启用新路径；默认`v2`保留旧接口。所有v2源文件与runner哈希共同绑定控制门，grounded门不能被旧v2回执放行。
- 观察模板直接给完整grounded JSON样例，不能在旧样例后追加相互冲突的字段要求。仅未提供可选`other_views`时取空集合，即“无跨视角佐证”，不推断像素或持物事实；关键事实字段仍严格校验。逐调用保留原文及`validation.defaulted_fields`，0隐藏重采样。此修复通过原始失败回答离线回放/96 CPU，尚未新物理复验。
- RGB-D读取前执行4次仅渲染更新，三相机RGB/深度共享snapshot编号，采集前后本体q必须静止。reset后annotator可能残留旧视角，不能因数组大小/hash合法就认为是当前图；d2da0ac的task3第一帧已人工发现此问题，保留作回归，不冒称搜索成功。渲染刷新方案仍须新物理门核验，不消耗机器人动作步。
- APPROACH保留2mm/1cm/3cm；先试有几何收益的方向，并保证相同方向2mm备选。ALIGN/INTERACT为微平移和六个微转轴保留位置，显式开夹不会被长候选列表挤掉。
- VLM只允许返回当前可行列表中的一个动作。执行前再次读取q并做完整预检，执行中的失跟踪/限位/自碰撞停止仍生效。候选预检从主控制器的**命令锁存**复制夹爪状态，不能从持物时的开度推回成打开指令。
- 底盘平移另外检查当前可见深度覆盖与近场障碍；没看过的后方不当成自由空间。可见点云、0.34m底盘圆和手臂胶囊只是保守局部否决器，**不是完整环境碰撞规划**，未观测障碍/被持物几何仍有局限。控制门中的显式运动是单独登记的工程检查，不称已通过全场景避障。
- 看不见目标时，搜索器选择单次8°扫描，不必再向VLM问一个毫无几何依据的小动作；每个动作后仍调用VLM重新观察。完整本地扫描找不到目标时，允许VLM基于当前图像选择左右扫描/有限可见方向换位/停止。换位最多5次6cm，每步重新检查，不是一口气走30cm。累计搜索平移≤1.2m、绝对转角≤720°，另受回合决策/控制/墙钟上限约束。
- 恢复仅调整当前策略，不改原目标序列、完成记录或持物占用；最多2次，不能消除硬安全停止。达到任何预算都明确记录原因，不把“所有计划用完”视为任务成功。
- APPROACH→ALIGN需要可用深度下目标距夹持中心≤8cm；夹取还需视觉包围及≤6cm，而不是只因目标出现在腕图。验证随动至少有5mm实际手部位移；无深度/换相机/底盘同时动则不能通过几何随动检查。小位移深度噪声会造成保守拒绝，不能伪造阳性补齐。

## 仍然有限的地方

### H-08 B4：观察隔离、候选完整性与自身外壳

观察器不再接收上帧目标像素/3D点、候选收益和搜索覆盖；只给当前子目标、本体、最后实际动作与运动，以及标明时间的图像。动作选择器仍接收本轮几何和执行反馈。四保存状态验证减少了重复旧数值，但边缘桌面/椅背定位仍不完全可靠，不能称此修改解决了VLM空间理解。

动作候选按不同物理方向分配，包含相机坐标对角方向及每个方向2mm备选，不让不可达forward耗尽平移槽。ALIGN保留1°和3°六轴旋转；未持任何物体的pick可以提出2cm底盘/3mm躯干调整，仍经过新鲜深度、关节及路径门。接触点超过10cm退回APPROACH，进入ALIGN仍为8cm；不因阶段自报而认证抓取。里程计后的停止判断明确保留原最多两次策略恢复权限，不能提前短路或擦掉硬停止。

两腕能看见自身底盘壳体；只剔除手臂胶囊/夹爪会把壳体当障碍，使所有底盘平移被拒。B4从**机器人定义指定的base_footprint_link**导出其visual mesh，保留完整局部三角面和FK；只有到该表面≤6mm的深度点作为自身回波排除，不按整个包围盒或任意近体区域删除。其余视图和外界点仍参与避障，自身点不能认证外界自由空间。没有场景语义分割、物体或全局pose输入。贴壳外物与深度误差、其余本体部分、未见障碍仍是局限；真实导出/门待验证，不能冒称完整碰撞安全。

### H-08新增：经过RGB-D核验的底盘运动记忆

旧逻辑将30Hz采样的底盘关节角速度积分直接当真实朝向。工程probe确认每步确实1/30秒，但实际每次约6.92°，积分却随方向/时刻为7–9°；由此会提前标记“已经扫完一圈”，也会误报底盘未达标。不是简单dt错误，不能套经验倍率。

`--visual-odometry`使用当前/上次head RGB-D、相机内参以及随本体q变化的相机外参估计相邻机身运动：SIFT匹配＋两端稳定深度＋RANSAC/PnP＋重投影和3D对应一致性检查。至少25内点、45%支持，像素中位误差≤1、3D中位误差≤1.5cm，并有单微动作位移硬界。新观察通过后才累积覆盖；失败安全停，不退回旧偏置积分，也不使用仿真真位姿、全局地图或目标真值。深度不足/纹理不足及动态场景仍是明确限制。

VLM下一次观察前接收已经修正的本体运动反馈，原速度积分留在`base_velocity_integral_raw`和原执行日志；仅旧“底盘残差”通过/失败可以按新测量重判，碰撞、关节限位、失跟踪、中断等硬停止不能擦掉。原SafeServo控制轨迹不改，动作23维与时间尺度不变。

工程真位移只由独立probe写入诊断文件，不属于生产估计器输入。回放原两策略55相邻对和probe9对全部通过；probe位置分量最大差1.92/4.24mm、转角最大差0.127°。这是局部开发验收，不是全场景SLAM或无漂移保证。开关/源digest绑定新的真实门，旧门不能放行。

### H-08新增：可拒绝的局部表面细定位

`--refine-grounding`是独立开关，默认为false，不改变旧H-07/B1。自由输出UV被原深度判据拒绝时，`affordance.py`在同一相机/同一时刻的小窗口内用原5×5深度门提出最多12点。原始局部图与编号图分开提供，VLM通过`ground`有限语法返回`candidate_id`或null；绝不自动选择最近点。放大只用已有像素，不引入检测/分割真值或新图像信息。

每回合最多16次附加选择，未见目标/无稳定点/已有效/抓取与完成验证阶段不调用。新点丢弃未重新确认的跨视图对应和随动声明，不能认证持物；只有通过当前状态的原动作预检才可执行。服务声明支持ground后才允许refined回合；控制门同时绑定源digest与开关。记录原观察原文、候选、裁剪、原深度拒绝、模型选择及新预检，允许离线定位是识别、选点还是控制失败。

`static_refine.py`固定旧H-07两个radio状态（call4/6），最多2次神经选择/0执行，另有prepare-only供人工先检查。104项本地和robo CPU回归通过；当前真实选点/物理收益仍待H-08验收，不能以“稳定深度”证明“可抓取姿态”。[新实验及预算](experiments/2026-09-18-semantic-agent-effect.md)

RGB-D点定位并不解决可抓取姿态、遮挡关系、长距离SLAM或有接触操作。7cm跨视图阈值用于拒绝明显不同点，不代表7cm操作精度；表面点也可能是模型误指的背景。机器人夹持中心只在实际开合/多姿态门验证后使用，不盲目信任18维FK能表示手指自由度。

高层与精确微动作依然分离，FM/MEM-Lite对照未修改。以后若引入VLA技能或微调，应明确目标/同状态动作监督，不能将本轮“通过安全门”当训练标签或方法已胜出的证据。
